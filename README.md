# MAX Chat · GREEN-API

Тестовое задание «Фронтенд-разработчик React»: веб-интерфейс для отправки и получения текстовых сообщений в мессенджере **MAX** через сервис [GREEN-API](https://green-api.com/max). Внешний вид — по мотивам [web.max.ru](https://web.max.ru/).

## Возможности

- Вход по учётным данным инстанса GREEN-API: `idInstance`, `apiTokenInstance`, `apiUrl` (подставляется по `idInstance`, можно изменить). Данные проверяются методом `getStateInstance`.
- Создание чата по номеру телефона получателя. Номер проверяется методом `checkAccount`, который возвращает `chatId` пользователя MAX.
- Отправка текстовых сообщений методом [SendMessage](https://green-api.com/v3/docs/api/sending/SendMessage/): статусы «отправляется», «отправлено», «ошибка» и повторная отправка.
- Получение сообщений по технологии [HTTP API](https://green-api.com/v3/docs/api/receiving/technology-http-api/): цикл `ReceiveNotification` → обработка → `DeleteNotification`.
- Входящие от новых собеседников создают чат автоматически. Сообщения, отправленные с телефона, тоже появляются в чате.
- Чаты и переписка сохраняются в `localStorage` отдельно для каждого инстанса.
- Адаптивная вёрстка: на узком экране показывается либо список чатов, либо открытый чат.

## Стек

- React 18 + TypeScript
- Vite 4 (работает на Node.js 16+)
- CSS Modules + БЭМ: у каждого компонента свой `*.module.css`, классы названы как `block__element--modifier`
- Без сторонних UI-библиотек и менеджеров состояния (`useReducer`)

## Локальный запуск

Требуется Node.js 16 или новее и npm.

```bash
npm install
npm run dev
```

Откройте http://localhost:5173.

Сборка для публикации:

```bash
npm run build
```

Готовые файлы появятся в `dist/`. Пути в сборке относительные, поэтому папку можно разместить на любом статическом хостинге. Посмотреть сборку локально: `npm run preview`.

## Подготовка инстанса GREEN-API

1. В [личном кабинете](https://console.green-api.com/) создайте инстанс для MAX и авторизуйте его (привяжите аккаунт MAX).
2. В настройках инстанса **оставьте пустым `webhookUrl`** и включите получение уведомлений о входящих сообщениях (при желании — и об исходящих). Иначе метод `ReceiveNotification` ничего не вернёт.
3. Скопируйте `idInstance`, `apiTokenInstance` и `apiUrl` и введите их на странице входа.

## Сценарий проверки

1. Войдите с учётными данными инстанса.
2. Нажмите «+», введите номер получателя (например, `+7 999 123-45-67`) и нажмите «Создать чат».
3. Напишите сообщение и нажмите Enter (Shift+Enter — перенос строки).
4. Получатель отвечает в MAX, и ответ появляется в чате в течение нескольких секунд.


⚠️ Важно для тестирования:
Для корректной проверки работы чата вам понадобится второй телефонный номер (отличный от того, который привязан к инстансу Green-API).
В поле ввода «Номер телефона получателя» укажите этот второй номер.
Отправка сообщений на собственный номер (номер инстанса) может не отображаться в чате из-за ограничений мессенджера.

## Ограничения

- Поддерживаются только текстовые сообщения (по условию задания). Другие типы уведомлений удаляются из очереди и не показываются.
- История чатов хранится только в браузере; старую переписку из MAX приложение не загружает.
- Учётные данные хранятся в `localStorage` до нажатия кнопки «Выйти».
